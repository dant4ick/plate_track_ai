# Типографика

Montserrat — единая гарнитура для английской и русской локалей во всех трёх
темах. `AppTheme.fontFamily` задаёт её для обычной и основной текстовых тем,
а также заголовков AppBar. Подписи диаграмм наследуют стиль из текущей темы.

В APK включены полные TTF для весов 400, 500, 600 и 700: обычные и курсивные
начертания. Они содержат латиницу и кириллицу, включая Ё/ё. Загрузка шрифта
по сети и зависимость `google_fonts` удалены. Холодный запуск без сети
использует те же файлы, что и запуск с сетью.

Файлы и лицензия SIL OFL 1.1 находятся в `assets/fonts/Montserrat`.
`sources.json` содержит ссылки, размеры и SHA-256 исходных файлов.
Лицензия также включена в ресурсы APK.

Цифры штрихкода используют системный `monospace`. Иконки и emoji используют
свои шрифты. Обычный текст интерфейса в обеих локалях использует Montserrat.

`test/themes/app_typography_test.dart` проверяет назначение гарнитуры обеим
локалям, наличие восьми начертаний в ресурсах и покрытие букв переводов
по таблицам `cmap` самих TTF. Превью с другими шрифтами находятся только
в тестовых инструментах и не входят в приложение.
